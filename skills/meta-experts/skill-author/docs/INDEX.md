# 문서 인덱스

이 디렉토리에는 `skill-author` 스킬의 상세 문서가 있습니다.

## 사용 가능한 문서

### [GUIDELINES.md](GUIDELINES.md)
구현 가이드. 게이트/워커 구조, 판정 로직을 한 곳에 두는 이유, `scaffold.sh` 확장 절차,
반복해서 밟은 함정을 다룹니다.

### [REFERENCE.md](REFERENCE.md)
레퍼런스. `scaffold.sh`의 전체 옵션, 상호작용 모델별 파생 결과표, 생성 파일 목록,
종료 코드와 검증 규칙.

### [CHANGELOG.md](CHANGELOG.md)
버전별 변경 이력.
