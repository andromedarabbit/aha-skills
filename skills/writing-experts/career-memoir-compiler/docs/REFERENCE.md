## 에이전트 호출 계약

### career-memoir-compiler-worker (생성)

| 항목 | 내용 |
|------|------|
| 호출 | `Task(subagent_type="career-memoir-compiler-worker")` |
| 도구 제한 | `Read, Write` (하드 제한) |
| 입력 3종 (전부 절대경로) | 상태 파일 / 세션 원문 경로 목록 / 장면표 위치 + 산출 위치(초안 저장 경로) 지시 |
| 임무 | 세션 원문 **전체를 먼저 읽고** 목소리 파악 → 장면표 단위로 저자 발화 조립(저자 발화 우선 인용) → 각 장면 끝에 근거가 된 세션·인용을 각주 표기 |
| 근거 없는 서술 | 금지 — 원문에 없는 사실·해석·연결을 창작하지 않고, 재료가 부족하면 비워둔다 |
| 산출 | draft 파일(지시받은 경로) + **조립 보고**(장면별 사용 인용 수, 부족·애매 장면 기록) |
| 목소리 | **컴파일 시점에 세션 원문에서 도출 — 별도 목록 상태 없음** (spec §4.4 "목록 참조"의 의도적 편차, 스테일 방지) |
| 대화 | 사용자와 대화 불가 — 질문하지 않는다 |

### career-memoir-auditor (감사)

| 항목 | 내용 |
|------|------|
| 호출 | `Task(subagent_type="career-memoir-auditor")` — worker와 **별개 호출(독립성)** |
| 도구 제한 | `Read, Grep` (읽기 전용 하드 제한 — 수정 불가) |
| 입력 (전부 절대경로) | 감사 대상 초안 / 세션 원문 경로 목록 / 상태 파일 |
| 판정 단위 | 초안의 각 서술 단위(문장 ~ 짧은 단락), 인터뷰 기록과의 **의미적 대조** (Grep은 후보 탐색 보조만) |
| 판정 3단계 | 근거 있음 / 부분 근거 / 근거 없음 |
| 연결문 | 장면 사이 전환 서술은 별도 표기 후 판정에서 **제외**(무한 교정 루프 방지 안전 밸브) |
| 산출 | 감사 보고서(판정별 문장 목록 + 위치 + 이유) — Write가 없으므로 **응답 텍스트로 반환** |
| **통과 정의** | **근거 없음 판정 0건 (연결문 제외).** 부분 근거는 통과를 막지 않고 교정 후보로 보고만 한다 |

## 루프·버전 규칙 요약

- **루프 상한 2회** — 초기 감사 1 + 교정 후 재감사 1. 재감사에서 근거 없음 0건이면 통과,
  남으면 사용자 보고 후 중단(자율 루프 연장 금지).
- **버전 규칙** — N은 감사 통과 확정 시 증가, 교정 라운드는 같은 버전 내 수정.
  문서 말머리에 rev 주석(버전·작성일·감사 통과 회차).
- **교정 방법** — 삭제 또는 인터뷰 기록 내 근거로 대체만 허용. 새 사실 창작 금지.
