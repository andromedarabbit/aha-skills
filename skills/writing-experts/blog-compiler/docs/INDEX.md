# 문서 인덱스

이 디렉토리에는 blog-compiler 스킬의 상세 문서가 있습니다.

## 사용 가능한 문서

### [GUIDELINES.md](GUIDELINES.md)
구현 가이드. 게이트 설계, 7단계 프로토콜, 테스트 방법을 다룹니다.

### [REFERENCE.md](REFERENCE.md)
레퍼런스. 에이전트 호출 계약, 게이트 판정식, 파일 레이아웃 등 상세 정보를 제공합니다.

## 팁

- 에이전트는 사용자가 명시적으로 요청하지 않는 한 이 문서들을 읽지 않습니다. WORKER.md도 게이트가 워커 프롬프트에 절대경로로 넘겨 읽게 합니다.
- 사용자는 [README.md](../README.md)로 시작하고, 이 인덱스로 상세 문서를 탐색하세요.
