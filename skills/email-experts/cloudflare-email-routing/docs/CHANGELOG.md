# 변경 이력

## 0.3.0 — 2026-11-03

- `healthcheck.sh` 리포트에 `기준: baseline captured_at=<날짜>`를 자동 표기한다. 카드 템플릿의 기준선 표기가 에이전트 기억에 의존하지 않게 하기 위함 (벤치마크 iteration-1에서 captured_at 누락 편차 관찰).
- 플레이북 카드 규약에 게시 절차(orca-cli 스킬)를 추가했다.

## 0.2.0 — 2026-11-03

- 헬스체크 무인 계약에 카드 대상 규약을 추가했다. 카드 대상은 프롬프트의 `카드:` 줄로 지정하고, 없으면 `--md-out` 파일 경로만 보고하고 끝낸다 (실측: 카드 대상 없이 실행돼 보고가 대화에만 남은 사례 반영).
- `--md-out` 파일을 판정·보고 기준으로 삼는 규약을 추가했다. stdout과 파일에 같은 리포트가 나오므로 되묻지 않는다.

## 0.1.0 — 2026-10-25

- 최초 릴리스. 모드 4종(인시던트·온보딩·헬스체크·리포트 분석)과 쓰기 게이트 규약.
- `healthcheck.sh` (C1~C7, dig 우선, cf 보조), `dmarc_report.py` (stdlib 집계), `notify.sh` (CF 우선, Mailgun 폴백).
- 기준값은 `assets/baseline-schema.json` 파라미터로만 받는다. 스킬 파일에 실측값을 넣지 않는다.
- 리서치 R1~R10 결과를 `docs/REFERENCE.md` 5절에 기록. R1(Email Sending 활성)은 권한 부족으로 미확정, R9 발송 드라이런은 보류.
