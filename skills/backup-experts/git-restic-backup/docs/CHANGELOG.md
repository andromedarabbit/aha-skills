# 변경 이력

## 0.3.0

- macOS File Provider 폴더(Google Drive 데스크톱 앱 등)를 목적지로 다루는 규칙을 추가한다. 경로 존재로 제공자를 인정하지 않고 제공자·계정·경로를 사용자와 확인하며, 확인 불가·변경 시 중단하고 다른 폴더로 대체하지 않는다.
- `scripts/check-file-provider.sh`로 읽기 전용 증거(도메인 디렉터리 대조, `fileproviderctl evaluate` 항목 인식)를 확인하고 없으면 중단한다. 계정 신원은 증명하지 못하는 한계를 명시한다. 가짜 도구 기반 동작 테스트와 평가 3건을 추가했다.
- `check-file-provider.sh`가 종료코드 0과 비어 있지 않은 출력만으로 통과하던 결함을 고친다. 실측한 출력 구조를 모두 요구하고 경고만 출력·빈 항목·형식 변경은 중단한다(출력 형식은 비계약이라 한계로 명시). 2·3단계 Markdown 분리, 신규 대상은 상위 경로 검사로 명확화.
- File Provider 대상의 백업·검사·복원 결과는 로컬 관점으로 보고하고 서버 업로드 완료는 확인 전까지 미확인으로 둔다.

## 0.2.0

- 외부 restic 스킬 없이 `restic` CLI를 직접 호출한다. 저장소를 명시하고 해당 백업의 스냅샷 ID를 확인한다.
- 원본의 상위 폴더 제한을 없애 현재 또는 지정한 Git 저장소 폴더를 백업한다.
- 호출 이름을 `git-restic-backup`으로 변경한다. 기존 개인 설정은 새 이름의 파일로 자동 이전하지 않는다.
- 매번 로컬 또는 마운트된 볼륨을 선택할 수 있고, restic 저장소 전체 경로와 백업 루트 지정을 구분한다. 내장 목적지는 없다.

## 0.1.1

- Git 이력이 원본 밖에 있거나 복원 시 포인터가 깨지는 저장소를 백업 전 중단한다.

## 0.1.0

- Workspace 저장소별 수동 restic 백업과 승인·중단 절차를 추가했다.
