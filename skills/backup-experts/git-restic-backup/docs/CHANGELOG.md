# 변경 이력

## 0.2.0

- 외부 restic 스킬 없이 `restic` CLI를 직접 호출한다. 저장소를 명시하고 해당 백업의 스냅샷 ID를 확인한다.
- 원본의 상위 폴더 제한을 없애 현재 또는 지정한 Git 저장소 폴더를 백업한다.
- 호출 이름을 `git-restic-backup`으로 변경한다. 기존 개인 설정은 새 이름의 파일로 자동 이전하지 않는다.
- 매번 로컬 또는 마운트된 볼륨을 선택할 수 있고, restic 저장소 전체 경로와 백업 루트 지정을 구분한다. 내장 목적지는 없다.

## 0.1.1

- Git 이력이 원본 밖에 있거나 복원 시 포인터가 깨지는 저장소를 백업 전 중단한다.

## 0.1.0

- Workspace 저장소별 수동 restic 백업과 승인·중단 절차를 추가했다.
