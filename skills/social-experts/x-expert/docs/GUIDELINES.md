# X 전문가 구현 기준

## 선택 이유

소재·보이스·문안에 대한 여러 차례 피드백이 핵심이며 계정·사진·게시 승인도 필요하다. 질문은 주 대화에서 수행하고 무인 실행은 읽기·비교·보고로 제한한다.

## 변경 경계

공통 CLI·상태·미디어·승인·게시 코드는 sibling social-posting을 재사용한다. 전문가별 wrapper·설정·승인 훅을 추가하지 않는다. X 작성 규칙은 [플레이북](playbook.md), 실행 순서는 SKILL.md가 정본이다.

연결 테스트는 이 전문가의 플랫폼·경로·지원 범위·게이트만 검사한다. 공통 게시 회귀와 실제 서비스 UI 검증을 대신하지 않는다. 셸의 SKILL_DIR 정의는 [README](../README.md)를 따른다.
