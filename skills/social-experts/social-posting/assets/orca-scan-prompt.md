# Orca 읽기 전용 교차 게시 후보 조사

단일 플랫폼이면 해당 전문가, 선택 그룹이면 social-posting으로 최근 글을 조사한다. 조회 대상이 명시되면 그 플랫폼만 읽고, 생략하면 Facebook·Threads·X·Bluesky 중 바인딩된 플랫폼을 쓴다. Instagram 사진 피드는 명시적으로 선택했을 때만 관찰하며 기본 네 플랫폼에는 추가하지 않는다. 실제 UI는 미검증이다. LinkedIn 최근 글 scan은 지원하지 않는다. 이 프롬프트는 자동화 등록 명령이 아니다. 실행 주기·후보 큐·알림·중복 실행 방지는 Orca가 관리한다.

- 기간을 지정하지 않았으면 최근 24시간이다. 시작 시 timezone을 포함한 `until`을 고정하고 `since`를 계산한다. 명시 기간은 그대로 사용한다. 모든 플랫폼에 같은 `[since, until)`을 전달한다.
- 호출자가 준 작업 루트를 쓴다. 루트가 없으면 임의로 정하지 말고 보고 후 종료한다. 스킬 경로는 설치된 social-posting 경로에서 확인한다. 이 파일에서는 하네스 경로 변수가 치환되지 않는다.
- preflight로 바인딩을 확인한다. 바인딩된 플랫폼만 scan한다. 미바인딩 플랫폼·접근 실패·시간 미상을 빈 결과로 숨기지 않는다. setup·로그인 변경·계정 선택을 하지 않는다.
- 플랫폼별 scan 결과·manifest·digest·coverage를 보존한다. 반환된 manifest 경로를 이후 관찰 근거로 사용한다. 다른 플랫폼 결과를 덮어쓰지 않는다.
- 사진 전용 글과 시간을 알 수 없는 글도 보존하되 시간 미상을 최근 글로 확정하지 않는다.
- 관찰된 parent 관계로만 답글을 묶고 확인된 기존 게시 기록과 비교한다. 유사 후보는 자동 제외하지 않는다. 대응 글 미발견은 관찰 범위 내 결과일 뿐 미게시 확정이 아니다.
- 사용자 입력·초안 확정·사진 선택·승인·게시·재시도·automation 등록이나 변경을 하지 않는다. 승인 영수증이 남아 있어도 게시하지 않는다.

## 종료 보고

조회 기준 시각·timezone·since/until, 플랫폼별 바인딩·coverage·중단 이유를 적는다. 후보별 원본 플랫폼·ID·URL·실제 게시자·시각·사진 관찰 ID와 alt·대상 플랫폼의 비교 근거를 적는다. 시간 미상과 불완전 수집을 별도로 표시한다.

다음 수동 세션이 이어받을 작업 루트·scan 디렉터리·manifest 경로·digest·후보 ID를 남긴다. 수동 세션에서 후보·계정·사진·alt·권리를 확인하고 초안을 준비한다. 이 scan 전용 작업에는 게시 권한이 없으며 Instagram 기본값이 private여도 게시하지 않는다. 별도로 게시를 요청하거나 사전에 허용한 게시 작업에서만 Instagram private를 기존 친한친구 대상으로 확인한 뒤 추가 사람 승인 없이 발행할 수 있다. public과 다른 플랫폼은 유사 후보 확인과 별도의 `게시 승인`이 필요하다. Threads 게시는 `THREADS_UNVERIFIED`로 계속 차단된다. Instagram 웹의 실제 대상 선택 지원은 미확인이며, 친한친구 대상이 없거나 불명·불일치하면 중단하고 public이나 팔로워 공개로 대체하지 않는다.
