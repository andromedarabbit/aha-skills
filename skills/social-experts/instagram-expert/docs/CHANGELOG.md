# 변경 이력

## 1.1.0 — 2026-11-19

- 전면 게시 차단 대신 기본 private(기존 친한친구 실게시)와 public 사람 승인을 구분한다. 조회·초안은 게시 의도가 아니며 명시적/사전 허용 게시 작업의 private만 건별 승인을 생략한다.
- 실제 composer의 대상·계정을 Share 직전에 재확인하고 불명·불일치면 중단한다. 팔로워 공개·계정 설정/목록 변경·public 대체는 허용하지 않는다.
- public의 캡션·사진 sha256/순서/alt·계정·범위를 사람 승인에 묶고 변경은 재승인한다. 일반 로컬 사진을 포함한 모든 Instagram 사진을 읽기 전용 사본으로 동결한다.
- 게시 결과의 정책 허용/사람 승인과 사후 read-back의 캡션·사진·범위 검증을 분리한다. POSTED·결과 불명·부분 게시의 재시도 금지와 혼합 작업·전체 계정 스냅샷을 보존한다.
- private/public 판정 문구와 공백 설치 경로의 연결 검사에 정책 손상 감지를 추가한다. UI는 합성 fixture만 검증했으며 실서비스는 미확인이다. 실계정·사진 업로드·게시 검증은 별도 승인 대상이다.

## 1.0.0 — 2026-11-18

- Instagram 독립 전문가를 추가했다. 조회·비교·초안·기존 초안 게시 요청·bootstrap·read-back을 구분하고 선택한 동작에서 종료한다.
- 사진 1~20장·공통 캡션·빈 캡션·각 alt·순서·권리·잘림 확인과 2200 Unicode codepoint 로컬 초안 정책을 명시했다.
- 공통 실행층과 상태 형식을 재사용하며 기존 혼합 작업·다른 초안·전체 계정 매핑·게시 기록을 보존한다.
- 게시 요청은 `INSTAGRAM_UNVERIFIED`를 보고한다. 최종 게시 승인 질문·영수증 생성·publish·직접 post를 진행하지 않는다.
- 전문가 연결·지원 경계·공통 Ready 문구를 자체 러너로 검사한다. 실제 계정·브라우저·사진 다운로드·업로드·게시의 검증을 뜻하지 않는다.

초안 피드백·사진 선택·권리 확인·보이스 검수·계정 확인을 실행 도중 반복해서 받아야 하므로 질문은 주 대화에 둔다. 현재 게시 차단을 해제하는 승인은 이 스킬 작성 범위에 포함하지 않는다.
