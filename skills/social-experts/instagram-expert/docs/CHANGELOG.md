# 변경 이력

## 1.0.0 — 2026-11-18

- Instagram 독립 전문가를 추가했다. 조회·비교·초안·기존 초안 게시 요청·bootstrap·read-back을 구분하고 선택한 동작에서 종료한다.
- 사진 1~20장·공통 캡션·빈 캡션·각 alt·순서·권리·잘림 확인과 2200 Unicode codepoint 로컬 초안 정책을 명시했다.
- 공통 실행층과 상태 형식을 재사용하며 기존 혼합 작업·다른 초안·전체 계정 매핑·게시 기록을 보존한다.
- 게시 요청은 `INSTAGRAM_UNVERIFIED`를 보고한다. 최종 게시 승인 질문·영수증 생성·publish·직접 post를 진행하지 않는다.
- 전문가 연결·지원 경계·공통 Ready 문구를 자체 러너로 검사한다. 실제 계정·브라우저·사진 다운로드·업로드·게시의 검증을 뜻하지 않는다.

초안 피드백·사진 선택·권리 확인·보이스 검수·계정 확인을 실행 도중 반복해서 받아야 하므로 질문은 주 대화에 둔다. 현재 게시 차단을 해제하는 승인은 이 스킬 작성 범위에 포함하지 않는다.
