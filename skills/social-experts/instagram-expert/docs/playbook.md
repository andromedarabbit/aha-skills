# Instagram 사진 피드 플레이북

## 지원 경계

- 사진 피드 한 건은 사진 **1~20장**과 **공통 캡션 하나**다. 빈 캡션은 허용하지만 사진은 필수다.
- `format: single`만 지원한다. 여러 사진을 스레드 세그먼트로 바꾸지 않는다.
- 캡션 **2200 Unicode codepoint 이하**는 이 저장소의 로컬 초안 정책이다. Instagram 웹의 공식 계수 단위를 입증한 값이 아니다.
- 영상·릴스·스토리·DM·댓글 체인·이미지 생성과 자동 편집·프로필 및 계정 설정 변경은 범위 밖이다.
- 사진 상한을 넘으면 사용자가 최대 20장을 선택한다. 자동 삭제·절삭·여러 게시물로 분할하지 않는다.
- 현재 Instagram 게시 실행은 `INSTAGRAM_UNVERIFIED`다. 캡션·사진 초안이 유효해도 게시 가능 상태를 뜻하지 않는다.

## 사진·권리·접근성

각 사진의 원본 출처·재게시 권리·선택 순서·alt·공통 방향·원본 비율 유지 의도를 확인한다. 로그인한 브라우저에서 볼 수 있어도 재게시 권리가 있다는 뜻은 아니다. 원본 게시자와 로그인 계정은 별개다.

alt는 관찰한 사진의 정보와 맥락을 설명한다. 캡션을 그대로 반복하거나 보이지 않는 인물의 정체·경험을 추정하지 않는다. 원본 alt가 없으면 설명을 제안하고 사용자에게 확인받는다.

사진이 없으면 사진 제공 또는 Instagram 제외를 확인해야 한다. 임의 이미지 생성·영상 변환으로 빈자리를 채우지 않는다. 원본 비율·잘림 의도가 미확정이면 최종 구성이 아니다. 모바일 이미지 비율 안내를 웹 업로드의 하드 제약으로 확대하지 않는다. UI 미리보기가 의도한 구성과 다르거나 잘림을 재현할 수 없으면 Share 전에 멈춰야 한다.

## 공통 캡션

사진의 맥락과 사용자 보이스를 기준으로 작성한다. UI 라벨·댓글·추천 글·생성 문안을 실제 게시 캡션 샘플로 사용하지 않는다. 빈 캡션을 임의 문장으로 채우지 않는다. 모르는 사실·숫자·경험은 추가하지 않는다.

티저 목적이면 훅과 링크 유도만 쓰고 본문 논지를 요약하지 않는다. 캡션 URL이 클릭 가능한 링크라고 약속하지 않으며 프로필 링크를 바꾸지 않는다. 해시태그 수·권장 길이·노출 효과에 근거 없는 하드 기준을 만들지 않는다.

## 관찰 결과의 해석

고정글은 최신순의 근거가 아니다. 동일 게시물의 캡션·시각·사진·작성자만 연결하며 댓글·추천 글·아바타·영상 썸네일은 제외한다. 시간 미상·일부 carousel만 관찰한 결과와 `coverage.complete:false`를 그대로 보고한다.

read-back에서 캡션 일치와 사진 수·순서·alt 확인 여부는 별개다. 확인하지 못한 사진 구성을 검증 성공으로 표시하지 않는다. `POSTED`의 URL 미회수는 실패가 아니며 `POST_UNKNOWN`·`PARTIAL_POSTED`를 자동 재게시 근거로 쓰지 않는다.

## 근거와 미확인 범위

다음 자료는 2026-11-18 구현 계획에서 확인한 근거다. 실제 계정·사진 업로드·DOM·Share·alt 적용의 실환경 검증 결과가 아니다.

- [Instagram Computer Help — 여러 사진 게시](https://help.instagram.com/269314186824048/): 최대 20장, 공통 캡션, 순서와 공통 방향의 근거.
- [Instagram 이미지 해상도 안내](https://help.instagram.com/1631821640426723/): 모바일 앱 기준 안내. 웹 업로드 하드 제약으로 옮기지 않는다.
- [UC Berkeley Digital Accessibility — 이미지와 캡션](https://dap.berkeley.edu/social-media/images): 캡션 2,200자 보조 자료. Instagram 웹 계수 단위의 근거는 아니다.

실환경 검증·검증용 차단 코드 변경·일반 사용 차단 해제는 별도 승인 대상이다. 일반 non-scan 로컬 사진에는 scan 사진과 같은 승인 후 파일 변경 방어가 없다는 한계를 유지한다.
